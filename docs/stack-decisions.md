# Stack decisions

| Suggestion                                 | Decision                                        | Reason                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------ | ----------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Next.js 15, TypeScript, Tailwind           | Adopted                                         | App Router, server rendering, typed domain, responsive UI. Lockfile pins installs; PostCSS is overridden to a patched compatible release.                                                                                                                                                                                        |
| Supabase PostgreSQL/Auth                   | Adopted                                         | Email-link sign-in, verified server-side identity, PostgreSQL persistence. Local integration tests use real GoTrue. Public tables have RLS enabled without browser-access policies; server queries enforce ownership.                                                                                                            |
| Drizzle                                    | Adopted                                         | Typed schema and ordinary profile/preference queries. Explicit parameterized SQL remains for row locks, fenced jobs and transactional itinerary writes. Reviewed, checksum-verified SQL migrations remain authoritative; never run `drizzle-kit push` against production.                                                        |
| OpenAI then Gemini                         | Adopted                                         | OpenAI is primary when configured. Gemini is tried if OpenAI is absent/unavailable or returns an invalid structured response. Both outputs go through the same Zod and domain validation; no text-to-database shortcut.                                                                                                          |
| Amadeus                                    | Adopted as optional live quote adapter          | Production flight and hotel quotes complement discovery. Sandbox data and missing consumer checkout links are significant limitations, exposed in code and UI.                                                                                                                                                                   |
| SearXNG vs OpenSERP                        | SearXNG selected                                | The inspected SearXNG source has a broader engine catalog (253 engine directory entries at the inspected revision), documented JSON API and active maintenance. Its pulled image was about 264 MB, versus OpenSERP's approximately 393 MB browser-backed image. This is a deployment comparison, not a search-quality benchmark. |
| Open-Meteo                                 | Adopted                                         | Weather forecasts and deterministic packing guidance; no invented long-range daily forecasts. Commercial use requires the appropriate subscription/license.                                                                                                                                                                      |
| Playwright scraping + mock niche providers | Not used in production                          | Browser scraping is brittle and may be disallowed by providers. SearXNG discovers provider pages; test fixtures cover closed-provider shapes. Official affiliate adapters can be added after access is granted.                                                                                                                  |
| Inngest or Upstash                         | Inngest selected                                | Durable HTTP steps, scheduled dispatch and serverless compatibility. A database outbox retains requests when immediate event delivery fails.                                                                                                                                                                                     |
| Vercel Hobby                               | Deployment compatible; no free-commercial claim | The application uses Node serverless handlers. Hobby eligibility, execution time and commercial restrictions must be checked for the actual deployment. SearXNG requires separate persistent hosting.                                                                                                                            |
| Quoted free-tier limits                    | Not treated as guarantees                       | Provider quotas, model availability, billing and eligible use change. Review current provider dashboards before launch. Amadeus test allowances do not imply free production inventory.                                                                                                                                          |
